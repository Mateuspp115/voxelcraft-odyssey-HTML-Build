CONTROLES

COMPUTADOR

  • WASD - mover
  • Mouse - olhar (clique na tela para travar o cursor)
  • Espaco - pular (toque duplo = voar, so no Criativo)
  • Shift - correr
  • Clique esquerdo (manter pressionado) - minerar
  • Clique direito - colocar bloco
  • 1 a 0 - selecionar item da barra rapida
  • Q ou E - abrir inventario
  • F - comer item selecionado
  • F3 - informacoes de depuracao
  • ESC - pausar

CELULAR

  • Direcional esquerdo - mover
  • Arrastar no centro/direita - olhar
  • Botao QUEBRAR (manter pressionado) - minerar
  • Botao COLOCAR - construir
  • Botao PULAR (toque duplo = voar, so no Criativo)
  • Botao VOAR - ativa/desativa voo no Criativo
  • Botao COMER - consome item selecionado
  • Botao mochila - abre inventario

SOBREVIVENCIA

  • Minere blocos para guarda-los; colocar gasta 1 unidade
  • Vida regenera com fome alta, cai a zero sem comida
  • Queda alta, lava, afogamento e cacto causam dano
