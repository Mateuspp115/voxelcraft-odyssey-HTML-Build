# Screenshots

O ZIP de origem não continha capturas de tela. Esta pasta é o local oficial para imagens revisadas do projeto.

Use nomes previsíveis, por exemplo `v14-menu-inicial-desktop.png` ou `v14-mundo-mobile.png`, e registre no commit a versão HTML, plataforma e resolução usada. Arquivos de trabalho não revisados devem ficar em `screenshots/local/`, que é ignorado pelo Git.
